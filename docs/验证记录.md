# 初版验证记录

本记录对应 0.1.0 的技能封装，使用 Python 3.12。本轮未安装技能，也未调用真实收费 API。

## 可重复的本地检查

```bash
python3.12 -m unittest discover -s tests -v
ruff check skills examples tests
git diff --check
```

自动测试共 88 项，包括：

- 真实 FFmpeg 合成音视频的非关键帧切点、完整解码、音轨、尺寸和时长检查。
- 16 kHz 单声道 WAV、抽帧、集锦顺序与不同尺寸拒绝。
- SRT、VTT、句级/词级 JSON 的严格导入，重叠字幕、中文与英文词边界、多声道拒绝及来源身份。
- 全文主题覆盖、核心与上下文关系、变体/重复编号及错误来源拒绝。
- 候选渲染、局部渲染仍保留全部备选、缓存哈希验证、修改切点后保留版本。
- 新转写保留旧稿并使旧计划失效，导入中断后恢复派生文件。
- 用户 CSV 与命令反馈冲突保留，旧反馈不迁移到新片段。
- 集锦在视频发布与来源清单发布之间中断后的恢复。
- 外部 API 的模拟鉴权、单次提交、未知提交不重交、429 与任务恢复、Range 校验、错误音频 URL 拦截。
- 将整个技能复制到临时目录后，直接执行入口并读取项目，无需安装或第三方 Python 依赖。

`examples/create_demo.py` 另外提供可直接打开的 13 秒合成演示：三条候选含一个长度变体、字幕、HTML 预览和集锦。演示为图形与测试音，字幕为虚构问答，不代表真实语音听审。
